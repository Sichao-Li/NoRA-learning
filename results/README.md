# Reported Results

These files contain saved results used in the manuscript. They are provided
for reading and plotting, without running models or judges.

| File | Contents |
| --- | --- |
| `scores.csv` | RAW and SFT scores used in the learning and transfer tables and plots |
| `morebench_dimensions.csv` | Positive fulfillment and negative avoidance in all six MoReBench Public dimensions |
| `coverage.csv` | Available, individually valid, and shared-valid counts |
| `paired_intervals.csv` | Previously calculated paired intervals; not regenerated by the plotting code |

## Columns

`scores.csv` records `benchmark`, `metric`, `dimension`, `level`, `model`,
`scope`, `arm`, `n`, and `value`. Values retain their original precision.
The model names identify size and RAW/SFT state.

- `arm=official` means the standard task prompt, not an endorsement of every
  adaptation as an official full-test evaluation.
- `arm=official_nora_cot` means the NoRA-style prompt.
- `scope=official` uses the shared-valid cohort for the standard prompt.
- `scope=joint_official_nora_cot` uses the same valid cases under both prompts.
- `n` is the number of units for that metric and dimension. It can count clips,
  dilemmas, or criteria. It is not interchangeable across benchmarks.

Rates and NoRA scores are stored as fractions. Plots multiply rates by 100;
changes in those rates are percentage points. Metrics are not normalized to
a common benchmark score. Missing results are not zeros.

See the paper for the cohort and evaluator behind each benchmark.
